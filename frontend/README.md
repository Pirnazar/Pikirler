# Pikirler — фронтенд

Веб-клиент Pikirler по макету `Pikirler.dc.html` (дизайн-система Modernist:
Archivo, нулевые радиусы, 2px-линейки), с тёмно-синим акцентом вместо
красного. React 18 + TypeScript + Vite, без UI-библиотек и роутера. Бэкенд —
[`../backend`](../backend).

## Запуск

Обычно ничего делать не нужно: `docker compose up` в `../backend` собирает этот
интерфейс в контейнер `web` (nginx раздаёт сборку и проксирует `/api`) и
открывает его на http://localhost:5470. См. `Dockerfile` и `docker/nginx.conf`.

## Разработка с горячей перезагрузкой

Нужны Node 20+ и запущенный бэкенд (API на `127.0.0.1:8460`).

```bash
npm install
```

```bash
npm run dev
```

Откройте http://localhost:5480. Vite проксирует `/api` на бэкенд, поэтому
браузер работает с одним origin: cookie сессии и CSRF работают без CORS.
Другой адрес API — переменная `PIKIRLER_API_URL`.

Войти можно владельцем, созданным в бэкенде (`pikirler create-owner`).
Регистрации нет.

## Продакшен

Образ собирается из `Dockerfile` вместе с остальным стеком
(`docker-compose.prod.yml`, сервис `nginx`). В продакшене его конфигурацию
заменяет `../backend/deploy/nginx.conf` с TLS, HSTS, CSP и лимитами запросов.
Отдельно собрать файлы можно командой `npm run build` — они окажутся в `dist/`.

## Типы API

`src/api/schema.d.ts` генерируется из OpenAPI бэкенда, вручную не правится:

```bash
npm run gen:api
```

| `src/Shell.tsx` | боковая панель, мобильная навигация, диалоги, горячие клавиши |

| `src/views/` | экраны: лента, мои мысли, закладки, темы, проекты, воспоминания, поиск, календарь, настройки, мысль |

## Языки интерфейса

Туркменский, русский и английский; переключатель есть на экране входа и в
настройках, выбор запоминается на устройстве. По умолчанию берётся язык
браузера (tk/ru, иначе английский).

- `en.ts` задаёт ключи, `ru.ts` и `tk.ts` обязаны содержать их все — иначе
  проект не скомпилируется.
- Числа с существительными — объекты с формами CLDR (`one`/`few`/`many`/`other`),
  поэтому «1 мысль, 2 мысли, 5 мыслей» склоняются правильно.
- Даты форматируются на выбранном языке. Для туркменского названия месяцев и
  дней недели встроены в код: многие браузеры не знают туркменскую локаль и
  иначе показали бы даты на другом языке.

## Чем реализация отличается от макета

Макет — прототип на локальных данных. Здесь всё работает с настоящим API, и
некоторые вещи из прототипа заменены:

- **Вход.** В макете пускало любое слово. Здесь сначала вход по email и паролю,
  затем Magic Word, если он включён в настройках. Без этого данные отдают 423.
- **Демо-журнал** («Sample», «Restore sample journal») и **симуляция офлайна**
  убраны: в продакшене нет фиктивных данных. Офлайн-баннер показывается при
  реальной потере сети; черновик хранится только на устройстве.
- **Распознавание речи.** Браузерный SpeechRecognition (в Chrome отправляет
  звук в Google) не используется. Аудио загружается на ваш сервер, расшифровку
  делает серверный ASR. Поле «Transcript» стало заметкой к записи.
- **AI.** Вместо `window.claude` используются эндпоинты `/ai/*` бэкенда:
  ответы строятся только по найденным мыслям, со ссылками на них. Внешний
  провайдер вызывается только при включённом «AI features».
- **«AI-suggested topics»** не сделаны: в API нет такого эндпоинта.
- **«Evolution of an idea»** строится по проектам и темам владельца (мысли по
  порядку), а не по захардкоженному списку.
- **Добавлено** то, без чего с настоящими данными не обойтись: создание и
  правка проектов, редактирование мысли (история правок хранится), корзина с
  восстановлением, черновики, подтверждение или отклонение связей, предложенных
  AI, смена Magic Word, часовой пояс, экспорт JSON/Markdown, выход.
