# Статус реализации

## Обновление: 2026-11-11 — Медиа и кино

- Реализованы архив YouTube с цветными превью, типами и пагинацией;
  кино с метаданными RU/EN, обеими дорожками субтитров и ручной загрузкой SRT/VTT.
- Общий поиск объединяет кино, YouTube и тексты песен; фильтры языка, типа,
  жанра и года, поиск по словам, локальный E5/pgvector и смешанный режим.
- Цитаты сохраняются в заметки со снимком источника, языком и таймкодом;
  повторное сохранение не создаёт дубль. Списки фильмов, избранное,
  личная оценка и комментарий защищены версионированием правок.
- Инкрементальная очередь сохраняет готовые данные и векторы. Архив читается
  только назначенным владельцем; отсутствие привязки закрывает доступ.
- Перед публикацией: **60 тестов прошли** (`test_media_search`, `test_cinema`,
  `test_auth`, `test_thoughts`, `test_isolation`) против настоящего PostgreSQL
  с миграциями и отдельного Redis. Внешние каталоги в тестах заменены двойниками.
  В тестах семантического ранжирования используются заданные векторы.
- Ruff для изменённых Python-файлов и сборка фронтенда (`tsc -b` + Vite)
  проходят. OpenAPI и TypeScript-типы перегенерированы из актуального кода.
- Отдельно на работающем сервере подтверждены получение RU/EN-субтитров,
  наполнение корпуса, работа настоящего локального ONNX encoder и выдача
  поиска по словам/смыслу. Это не проверка доступности всех внешних источников.
- Актуальный общий поиск и формы списков не прошли отдельную визуальную
  проверку в браузере; автоматические тесты API её не заменяют.

Настройка, ограничения источников и бэкапы — [MEDIA.md](MEDIA.md).
Проверки ниже относятся к базовой версии и не означают повторный прогон
всего старого набора при этом обновлении.

## Базовая версия: 2026-10-28

Состояние на 2026-10-28. «Проверено» означает: автоматический тест против
настоящих PostgreSQL 16 (pgvector, pg_trgm, миграции, триггеры), Redis, RustFS
и файлов на диске, либо ручная сквозная проверка запущенного стека. Внешние
AI/ASR-провайдеры в тестах заменены двойниками (`tests/fakes.py`).

Итог проверок: **95 тестов проходят**, `ruff` и `mypy --strict` без ошибок,
`alembic check` без расхождений, upgrade → downgrade → upgrade проходит,
`scripts/smoke_test.py` проходит против запущенных api + worker + RustFS,
`nginx -t` и `docker compose -f docker-compose.prod.yml config` валидны.

## Производительность (замер на 110 000 мыслях, EXPLAIN ANALYZE)

| Запрос | Время | План |
|---|---|---|
| Лента, первая страница | 0,02 мс | index-only scan `ix_thoughts_feed` |
| Лента, курсор на ~1600-й странице | 0,03 мс | index-only scan |
| Лента идей | 0,05 мс | index-only scan `ix_thoughts_type_feed` |
| FTS, редкое слово | 0,03 мс | bitmap GIN |
| FTS, частое слово (22 000 совпадений, ранжирование) | 42 мс | bitmap GIN + sort |
| On This Day | 22 мс | parallel seq scan |
| Fuzzy-fallback (только когда FTS пуст) | 95–130 мс | seq scan |

## Реализовано, но не проверено против настоящего внешнего сервиса

- **Gemini** (эмбеддинги и LLM), **OpenAI-совместимые** эмбеддинги/LLM/ASR,
  **remote_whisper**, **local_faster_whisper**: адаптеры написаны по
  документированным API, проверены типами и через двойники, но без реальных
  ключей и GPU-машины не вызывались.
- **asr_server/** (эталонный сервер для GPU-машины) — не запускался здесь (нет
  GPU и модели в этой среде).
- **Видео**: ffmpeg/ffprobe есть в образе, путь постера и длительности написан,
  но тестом с настоящим видеофайлом не покрыт (аудио-путь ffprobe выполнялся в
  тестах голоса без проверки результата).
- **Прямая загрузка в S3 по presigned PUT** — URL выдаётся при настроенном
  `PIKIRLER_S3_PUBLIC_ENDPOINT_URL`; проверен только presigned GET.
- **Скрипты backup/restore** — проверен синтаксис, полный цикл на живых
  данных не выполнялся.
- **Prod-стек** — конфигурация валидна, реальный деплой с TLS не выполнялся.
  Раздача собранного фронтенда через `deploy/nginx.conf` проверена в
  контейнере nginx с временным сертификатом: SPA, deep links, CSP, кэш.

## Фронтенд (`../frontend`)

Сделан по макету `Pikirler.dc.html`, акцент тёмно-синий. Вручную в браузере
против этого бэкенда проверены:

- вход и Magic Word (неверное слово, блокировка → 423, разблокировка);
- публикация на tk/ru/zh, хэштеги → темы, продолжение треда;
- правка с историей;
- загрузка изображения (SHA-256, превью без EXIF) и карточка ссылки;
- закладки, удаление с отменой;
- проекты: создание и добавление мысли;
- поиск: «yoryp» находит «ýöräp», китайский;
- темы, календарь, воспоминания;
- настройки: имя, тема, Magic Word;
- мобильная вёрстка: 375 px без горизонтального скролла, composer-лист.

Интерфейс на трёх языках (tk/ru/en): переключение, склонения и даты на
туркменском и русском проверены в браузере.

AI-панели показывают понятную ошибку, пока провайдер не настроен. Запись голоса
в браузере не проверена: нужен микрофон; эндпоинт `/voice/notes` покрыт
тестами бэкенда.

## Не реализовано

- **AI-предложения тем** («AI-suggested topics» в макете фронтенда) — эндпоинта нет.
- **Нативный импорт Second Brain и подключение к коду Jemşit** (`action_agent/`)
  — пока не реализованы. YouTube уже подключён через read-only SQLite-снимок
  (см. обновление выше); OAuth/Whisper и синхронизация исходной библиотеки
  остаются отдельными. Сам Jemşit не изменялся.
- **Возобновляемая загрузка по частям** (tus/multipart между запросами): при
  обрыве файл отправляется заново целиком (идемпотентно).
- **AI-сводки как фоновые задания**: AI-эндпоинты синхронные с таймаутом.
- **Перенос мысли в другой тред** (`parent_id` после создания не меняется).
- **Шифрование на уровне приложения**: рекомендуется шифрование диска
  и шифрованные бэкапы.
- **Метрики** (Prometheus и т. п.) — только логи с длительностью запросов.
- **Telegram-бот** — поддержан как источник и сервисный клиент, самого бота нет.

## Известные ограничения

- Fuzzy-поиск — полный проход (~0,1 с на 100k); при росте объёма перевести на
  оператор `<%` с GIN-индексом.
- On This Day — последовательное сканирование (22 мс на 110k); при росте —
  выражение-индекс по (месяц, день) в часовом поясе владельца.
- Экспорт JSON/Markdown собирается в памяти (десятки МБ на 100k мыслей);
  полный архив строится на диске воркера.
- Лимит входа хранится в Redis: при недоступности Redis вход отклоняется
  (fail closed).
- Образ RustFS закреплён на `rustfs/rustfs:1.0.4`; обновлять осознанно, прогнав тесты S3.
